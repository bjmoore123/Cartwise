## 5. Rollback

Restore files with `git checkout <last-good-commit> -- .` and redeploy (see `docs/promotion-checklist.md`).

There are no data migrations:
- Cache rows are unchanged; the API re-derives `offer` from them.
- The history summary rebuilds itself when its format version changes, in either direction.

v9.2.2 can't read v9.3's history summary format (format 3), and its `/deals/history` would return errors. After rolling back, delete each store's summary once so it rebuilds. Repeat the command for every store ID in use:

```bash
aws dynamodb delete-item --table-name cartwise-deal-history --key '{"store_id":{"S":"1546"},"sk":{"S":"_summary"}}'
```
