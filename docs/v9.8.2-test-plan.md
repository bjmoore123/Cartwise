# CartWise v9.8.2 — Test Plan (savings history)

**Flow:** automated tests → staging deploy → manual checks → Ben approves → production deploy.

## What changed

| Area | Before | After |
|---|---|---|
| Modal chart | "Price history": real prices only. BOGO and "$ off" weeks were missing, and a faint line ran straight across months off sale. | "Savings history": what Publix said each week saved per item (per lb for deli/meat). BOGO "save up to" is halved, since Publix states it for the pair. No estimates. |
| Gaps | Line joined every dot. | Line joins only consecutive on-sale weeks. Off-sale weeks get a tick on the baseline. |
| Deal type | Not shown. | Dot color = deal type: Sale green, BOGO amber, Multi-buy teal, Coupon purple, Extra Savings blue. |
| Unknown amount | Dropped. | Hollow dot on the baseline ("Amount not listed"). |
| Hover | Nothing. | Hover, tap or Tab to a dot: week, amount, type, Publix's text. |
| Text | 8–9 px, light grey. | 11.5–14 px, darker. Chart is taller (132 px). |
| Footer | "Price history · last N weeks" (store-wide N). | "This week: save … · best in N weeks · on sale X of N weeks" for this item, plus a key of what's shown. |
| Badge | "Lowest in N wks" (price). | "Biggest discount in N wks" (6+ past weeks with a stated saving, and they vary). |
| Multi-buy tag | Amber, same as BOGO. | Teal on cards and in the weekly email. |

The history summary moves to format 5, so each store rebuilds it on the first page load after deploy (a few seconds, once).

## 3. Manual checks on staging (hard-reload first)

**T1 · Chart.** Open a deal that has been on sale several times. **Pass:** the heading says "Savings history"; dots sit at the discount; there is no line across weeks it was off sale; ticks mark off-sale weeks; the text is easy to read.

**T2 · Colors.** Find an item with a BOGO week and a regular sale week. **Pass:** BOGO dots are amber, sale dots green, and the key lists only the types shown.

**T3 · Tooltip.** Hover a dot (desktop) and tap one (phone). **Pass:** shows "Week of …", the amount ("Save up to $2.85 ea"), the type and Publix's text. Tapping elsewhere on the chart hides it.

**T4 · Footer.** **Pass:** "This week: save …", then "best in N weeks" (or "best: … (Mon)"), then "on sale X of N weeks".

**T5 · Multi-buy tag.** Find a "2 for $X" deal. **Pass:** the tag is teal on the card and in the modal; BOGO stays amber. Optional: Admin → Send test email shows a teal "2 for" tag.

**T6 · Badge.** **Pass:** any history badge reads "Biggest discount in N wks"; none say "Lowest".

**T7 · Regression.** Deals load, filters work, BOGO card on My Store unchanged.

## 4. Rollback

No data is rewritten. Revert and redeploy; the summary rebuilds again in the old format.
